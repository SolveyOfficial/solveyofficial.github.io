# Solvey Tools

The home page for Solvey's free, browser-based tools:
https://solveyofficial.github.io/

- [Image Compressor](https://solveyofficial.github.io/image-compressor/)
- [PDF Tools](https://solveyofficial.github.io/pdf-tools/)
- [SVG Optimizer](https://solveyofficial.github.io/svg-optimizer/)
- [Whiteboard](https://solveyofficial.github.io/whiteboard/)
- [Diagram Editor](https://solveyofficial.github.io/diagram-editor/)
- [SVG Path Editor](https://solveyofficial.github.io/svg-path-editor/)

The page is plain HTML and CSS with self-hosted fonts and no tracking. Every
push to `main` is published to GitHub Pages.

The fonts' licences are in THIRD_PARTY_NOTICES.md.
